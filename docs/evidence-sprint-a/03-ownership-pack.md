## C. Call-handling script — “joining / GP interested”

**For reception (print at desk).**

### If caller says they are a GP interested in joining

1. **Warm + clear:** “Thanks for calling Woolloongabba Medical Centre — I can help with doctor enquiries about joining.”  
2. **Capture:** Name · preferred callback number · email · briefly “established / registrar / part-time?” if offered.  
3. **Expectation:** “Our practice manager reviews joining enquiries. I’ll pass this on and someone will get back to you.”  
4. **Do not:** Quote billings, promise sessions, negotiate terms, or say “we’re not hiring” unless PM has briefed a line that day.  
5. **Handoff:** Same day to PM (email/SMS per practice norm) with notes.  
6. **If PM unavailable:** “I’ve logged your details; the practice manager will return your call.”

### If they ask for HotDoc / patient booking by mistake
Redirect to usual patient booking path; do **not** mix joining with patient books.

### If they ask “who reads the website form?”
“The practice manager reads expressions of interest from doctors.”
