# WMC Evidence Execution Program

**Based on:** Approved Real-World Evidence Plan (`docs/WMC-ATTRACTION-REAL-WORLD-EVIDENCE-PLAN.md`)  
**Role:** Healthcare employer-brand production lead  
**Goal:** Cross the authenticity line with real Woolloongabba Medical Centre evidence  
**Constraints:** IA / navigation / journey frozen · No new modules  

Interactive summary: canvas `wmc-evidence-execution-program`

## 3. Interview run sheet

**Mode:** In person preferred (shoot afternoon / next day) · 15–20 min · record with consent  

### Per interview

| Step | Minutes | Action |
| --- | --- | --- |
| 1 | 2 | Confirm Quote Consent signed · attribution preference |
| 2 | 2 | Purpose: Attraction pages for GPs considering joining; optional withdraw |
| 3 | 10–12 | Prompts (below) — seek concrete, de-identified examples |
| 4 | 2 | “We’ll send 1–2 sentences for your exact approval” |
| 5 | — | Tag file `V-XX-01_raw` |

### Prompt cards

**GP (pick 4)**  
1. Day here vs elsewhere?  
2. How nursing changes a session?  
3. Continuity in the *book*, not the slogan?  
4. Who should *not* join us?  
5. What would you tell a GP still deciding whether to write in?

**Nurse (pick 4)**  
1. How do you protect GP consulting time?  
2. Handoff: flag → prep → GP join → recall (de-identified)?  
3. Thinner nursing-cover days?  
4. What must a new GP understand about nursing here?

**Reception (pick 4)**  
1. Matching appointment type to need?  
2. Enquiries that must not interrupt a consult?  
3. Running-late communication?  
4. What should GPs know about front-of-house before they start?

### Approval SLA

- Draft lines within **48 h** of interview  
- Interviewee approve/edit within **72 h**  
- No publish without written OK (email sufficient)
