# GP Attraction — Stakeholder Role Packs

**Parent pack:** `docs/WMC-GP-ATTRACTION-STAKEHOLDER-REVIEW-PACK.md`  
**Goal:** High-quality feedback with **minimal meeting time**  
**UAT:** `https://next.gabbamedicalcentre.com.au` (Join → PE → Catchment → Opportunities → EOI)  
**Facilitator canvas:** `attraction-stakeholder-role-packs`

---

## Facilitator cheat sheet (time boxing)

| Format | Duration | Use |
| --- | --- | --- |
| **Solo pre-read** | 15–20 min | Send role pack + link day before |
| **1:1 or role huddle** | **12–15 min** | Score 4–5 weighted areas only + 3 must-fixes |
| **Plenary** | 20 min | Only conflicts + decision criteria |

**Do not** run full 9-area scorecard live for every role — each version below marks **Primary** (must score) vs **Secondary** (optional if time).

**Demo path (all roles):** Join → Practice Experience → Catchment → Opportunities → Express Interest.  
Skip Continuity/Interests/tools unless that role’s pack asks.

## Shared micro-score (1–5)

| Score | Meaning |
| --- | --- |
| 5 | Launch-ready for my concerns |
| 4 | Strong — minor polish |
| 3 | OK for UAT — not production without a fix |
| 2 | Must change |
| 1 | Blocks launch from my seat |

# 1. Practice owner version

**Time:** 12 min live · 15 min pre-read  
**Lens:** Reputation · which doctors we attract · commercial / brand risk  

### Scoring emphasis (Primary)
| Area | Weight for owner |
| --- | --- |
| Trust | ★★★ |
| Authenticity | ★★★ |
| Practice fit | ★★★ |
| Opportunities | ★★ |
| Express Interest | ★★ |
| Continuity / Community / PE | ★ (skim) |
| Readiness tools | ignore unless embarrassing |

### Questions (answer in bullets)
1. Would you be comfortable with a peer practice seeing this as *us*?  
2. Does this attract the **right** GPs for our model — or the wrong volume/throughput profile?  
3. Any reputation risk in photos, vacancies, or claims?  
4. Top **3 must-fixes** before public Attraction?  
5. Ready · After must-fixes · Not ready?

### Likely concerns
- Brand dilution / looking like a recruitment platform  
- Over-promising continuity or list-building  
- Vacancy commercials without relationship context  
- Concept photography not “ours”

### Likely objections
- “Don’t launch until photos are real.”  
- “Too many optional tools — feels like a product.”  
- “We’re not hiring that profile.”  

### Discussion prompts (3 min)
- What would make you **proud** vs **uneasy** if this were shared in a GP Facebook group?  
- Soft-launch `noindex` vs wait for evidence shoot?

### Decision criteria (owner)
| Approve HOLD→next only if… | Block if… |
| --- | --- |
| Authenticity ≥3 and Trust ≥4 **or** written photo/voice plan dated | Trust ≤2 or clear overclaim |
| Must-fix list ≤5 and owned | Vacancy language you won’t stand behind |

# 2. Practice manager version

**Time:** 15 min live (ops-dense)  
**Lens:** Operational truth · EOI handling · capacity · sessions · nursing cover  

### Scoring emphasis (Primary)
| Area | Weight |
| --- | --- |
| Practice Experience | ★★★ |
| Opportunities | ★★★ |
| Express Interest | ★★★ |
| Authenticity | ★★ |
| Readiness tools | ★★ (ops embarrassment) |
| Community / Continuity | ★ |

### Questions
1. Can you defend every operational claim (sessions, cover, list-building, EOI reply)?  
2. Who reads EOI today — is that clear on the page?  
3. What would break if 5 EOIs arrived next week?  
4. Which sentences are **soft** or **wrong** in PE / Opportunities?  
5. Ready · After must-fixes · Not ready?

### Likely concerns
- Unstaffed EOI inbox  
- Session flexibility overstated  
- Nursing cover honesty vs marketing  
- Tools creating expectation of “assessment”

### Likely objections
- “Don’t publish EOI without a named owner.”  
- “Flexible Sessions chapter is unfinished.”  
- “Vacancies need my sign-off weekly.”  

### Discussion prompts
- What is the **minimum** EOI ownership line you will put your name behind?  
- Which PE honesty cues must stay verbatim?

### Decision criteria (PM)
| Pass | Block |
| --- | --- |
| EOI ownership named + PE claims ops-true (≥4) | EOI anonymous or capacity claims false |
| Punch-list owned with dates | Unowned must-fixes |

# 3. Principal GP version

**Time:** 12–15 min  
**Lens:** Clinical / continuity honesty · professional fit · peer credibility  

### Scoring emphasis (Primary)
| Area | Weight |
| --- | --- |
| Continuity positioning | ★★★ |
| Practice Experience | ★★★ |
| Practice fit | ★★★ |
| Trust | ★★ |
| Opportunities | ★★ |
| Clinical Interests | ★ (only if time) |

### Questions
1. Is continuity described as **operations** you actually run — or slogan?  
2. Would you send a registrar or colleague to this page set?  
3. What is clinically **off**, thin, or risky?  
4. Do photos/voices (when present) feel like colleagues you’d stand beside?  
5. Ready · After must-fixes · Not ready?

### Likely concerns
- Continuity overclaim  
- Throughput vs paced book misread  
- Interest scope without credentialing honesty  
- Synthetic or non-WMC faces

### Likely objections
- “Don’t say continuity unless booking habits match.”  
- “No fake GP quotes.”  
- “Opportunities image must look like our rooms.”  

### Discussion prompts
- One sentence: who should **not** join us — is that visible enough?  
- Which single page most needs a consented GP voice?

### Decision criteria (principal)
| Pass | Block |
| --- | --- |
| Continuity + PE ≥4; no clinical overclaim | Continuity ≤2 or invented voice pressure |
| Agrees “that is us” on Critical evidence plan | Refuses photography/voice gate |

# 4. Nurse version

**Time:** 10–12 min  
**Lens:** Nursing collaboration accuracy · safety · cover reality  

### Scoring emphasis (Primary)
| Area | Weight |
| --- | --- |
| Practice Experience (Nursing chapter) | ★★★ |
| Trust | ★★ |
| Authenticity | ★★ |
| Opportunities / Support mentions | ★ |
| EOI | optional |

**Pre-read focus:** PE → Nursing (+ skim Typical Day / Team). Skip tools.

### Questions
1. Does the Nursing chapter match how you actually protect consulting time?  
2. Is the handoff description safe and fair?  
3. Are thin-cover / capacity lines honest enough?  
4. Would you be comfortable being photographed / quoted (yes/no/conditions)?  
5. Ready · After must-fixes · Not ready?

### Likely concerns
- Overstating nursing capacity  
- Procedure claims without credentialing  
- Being shown in AI/concept images that aren’t them  

### Likely objections
- “We can’t promise that pathway every session.”  
- “Don’t imply instant nurse availability.”  
- “I won’t appear without consent and a real shoot.”  

### Discussion prompts
- Which **one** honesty cue must never be softened?  
- Who should speak for nursing on the site (role or named)?

### Decision criteria (nurse)
| Pass | Block |
| --- | --- |
| Nursing chapter ≥4 for accuracy | Capacity/safety overclaim |
| Consent comfort logged | Pressure to use synthetic nurse imagery |

# 5. Reception version

**Time:** 10–12 min  
**Lens:** Booking · interruptions · running late · joining phone calls · EOI reality  

### Scoring emphasis (Primary)
| Area | Weight |
| --- | --- |
| Practice Experience (Reception) | ★★★ |
| Express Interest | ★★★ |
| Authenticity (FOH photos) | ★★ |
| Community (skim) | ★ |

**Pre-read focus:** PE Reception · Join sticky CTAs · EOI. Skip readiness tools.

### Questions
1. Is reception described the way you actually work?  
2. “Enquiries that should not interrupt a consult” — fair?  
3. If a GP calls about joining, are you briefed — and does the site set expectations?  
4. Anything that would create angry or confused callers?  
5. Ready · After must-fixes · Not ready?

### Likely concerns
- Unrealistic “calm flow” claims  
- Phone/EOI volume without briefing  
- Photos of desk with readable screens  

### Likely objections
- “Don’t publish EOI until we know who answers.”  
- “Running-late wording must match what we say.”  
- “I need a joining-call script.”  

### Discussion prompts
- What should the site promise about **response** to EOI/calls?  
- One change that would make FOH proud of the Reception chapter?

### Decision criteria (reception)
| Pass | Block |
| --- | --- |
| Reception chapter ≥4; EOI/call path clear | Reception claims false or unstaffed contact |
| Joining-call brief exists (or dated) | Screens/privacy issues in photos |

# 6. External GP reviewer version

**Time:** 20–25 min solo (async OK) · optional 10 min debrief  
**Lens:** Cold GP · comparator · would I explore / write?  

### Scoring emphasis (Primary)
| Area | Weight |
| --- | --- |
| Trust | ★★★ |
| Authenticity | ★★★ |
| Practice fit | ★★★ |
| Practice Experience | ★★★ |
| Community | ★★ |
| Opportunities | ★★★ |
| Express Interest | ★★★ |
| Continuity / Interests | ★ skim |
| Readiness / Pack | ★ only if they notice |

### Questions
1. In 30 seconds on Join: curious or bounce? Why?  
2. After PE + Catchment: do you **understand** the place? Do you feel you **could work** there?  
3. What still blocks an EOI?  
4. Which page would you send a peer? Which would you hide?  
5. Compared with other practices you’ve seen online: stronger / same / weaker on honesty?  
6. Ready · After must-fixes · Not ready **as a visiting GP**?

### Likely concerns
- “Is this stock/AI?”  
- Missing human proof  
- Interstate/OTG logistics  
- Assessment-feeling tools  
- Unclear who reads EOI  

### Likely objections
- “I’d wait for a phone number conversation, not a form.”  
- “Too long before I know fit.”  
- “Feels like a platform, not a clinic.”  

### Discussion prompts (debrief)
- What single proof would move you from understand → EOI?  
- Did optional tools help or make you feel evaluated?

### Decision criteria (external GP)
| Signal to practice | Meaning |
| --- | --- |
| Trust + Authenticity + Fit all ≥4 and would EOI or call | Strong production signal |
| Understands place but would not EOI | Belonging/proof gap (HOLD) |
| Trust ≤2 | Do not launch Attraction publicly |
